Google Sheets

Entri yang diedit akan memperbarui barisnya di Sheets (tanpa duplikat). Menghapus entri hanya berlaku di aplikasi — barisnya di Sheets tetap ada.

Cara memasang / memperbarui script Google Sheets
  1. Buka Google Sheets → Extensions → Apps Script
  2. Hapus semua kode lama, tempel script di bawah, lalu Save
  3. Deploy → Manage deployments → ikon pensil → Version: New version → Deploy (deployment baru: pilih Web app, Who has access: Anyone)
  4. Tempel URL /exec di kolom di atas, lalu Simpan URL
